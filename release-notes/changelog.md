# DepthWard Camera 1.0.18 — Beta

First prepared public package for Minecraft 1.20.1 / Forge.

- Adaptive circular third-person terrain cutaway.
- Thin-wall camera stop near the far block face.
- Close-range player fading and optional rendering integrations.
- Floor/carpet support protection retained.
- Restored cutaway depth to the far side of the player bounds to reveal touching blockers.

Known limitations: experimental rendering, unsupported active shader packs, possible black polygons/clipping with complex geometry. In-game performance has not been benchmarked.
